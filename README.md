安徽工业大学晚寝自动签到系统 使用指南
 
本项目基于某GitHub开源库（原库地址可补充），通过 Google Gemini 与 字节跳动豆包 进行功能增强、BUG修复与逻辑完善，适配2026年安徽工业大学晚寝签到接口，新增Web管理面板、邮件通知、内网穿透、防重复签到等核心功能。
 
一、功能介绍
 
功能项 说明 
自动定时签到 每日21:30自动触发签到，覆盖学校规定的21:18-23:59签到时段 
Web可视化管理 提供登录、用户配置、手动签到、日志查看等可视化操作界面 
邮件结果通知 签到成功/失败后自动发送邮件提醒（需配置邮箱） 
内网穿透（Cloudflared） 无需公网IP，自动生成公网访问地址，可远程管理签到系统 
防重复签到 检测到已签到状态时自动跳过，避免重复提交导致的接口报错 
GPS偏移模拟 基于学校官方定位小幅偏移，模拟真实用户定位行为，降低风控风险 
多用户支持 管理员账号可管理所有用户，普通用户仅能查看/配置自己的信息 
完整日志记录 所有操作与签到流程均记录日志，方便排查问题 
 
二、环境准备
 
1. 基础环境
 
- Python 版本：3.8 及以上（推荐3.9/3.10，兼容性最佳）
- 操作系统：Windows（已适配 cloudflared.exe ），Linux/macOS需替换对应 cloudflared 程序
 
2. 依赖安装
 
将项目文件（ core_sign.py 、 main.py 、 templates 文件夹、 cloudflared.exe ）放在同一目录下，打开命令行执行：
 
bash  
# 安装核心依赖
pip install aiohttp fastapi uvicorn apscheduler yagmail sqlite3 jinja2
 
 
3. 必要文件准备
 
- 下载 cloudflared.exe 并放在项目根目录（Windows），Linux/macOS需下载对应版本并修改 CLOUDFLARED_PATH 配置
- 确保项目目录有读写权限（需自动创建 users.db 数据库和 logs.txt 日志文件）
 
三、核心配置修改
 
打开 main.py 文件，找到「核心配置区」，修改以下关键配置（必改项标★）：
 
配置项 修改说明 
★ ADMIN_STU_ID 填写你的学号，登录后将拥有管理员权限（可查看/管理所有用户） 
★ SMTP_USER 填写发送邮件的QQ邮箱（如 123456@qq.com ），用于接收签到结果通知 
★ SMTP_PWD 填写QQ邮箱的授权码（不是登录密码！需在QQ邮箱设置-账户中开启SMTP并生成） 
CLOUDFLARED_PATH 若 cloudflared.exe 不在项目根目录，填写完整路径（如 D:\sign\cloudflared.exe ） 
LOCAL_PORT 本地Web服务端口（默认8000，若被占用可修改为8080/9000等） 
 
补充：QQ邮箱授权码获取步骤
 
1. 登录QQ邮箱 → 设置 → 账户
2. 找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务」
3. 开启「SMTP服务」，按提示验证后生成授权码，复制填入 SMTP_PWD 
 
四、启动与使用教程
 
1. 启动系统
 
在项目根目录打开命令行，执行：
 
bash  
python main.py
 
 
启动成功后会看到：
 
- 日志提示「启动 Cloudflared 隧道...」
- 最终输出「🌐 内网穿透成功！公网访问地址: https://xxxx.trycloudflare.com」
- 本地访问地址： http://localhost:8000 （内网穿透地址可远程访问）
 
2. 首次登录配置
 
1. 打开浏览器，访问本地地址或公网穿透地址，进入登录页
2. 输入你的学号和安工大签到系统密码（默认密码若未改填 Ahgydx@920 ）
3. 点击登录，系统会自动验证账号密码并将你的信息存入数据库
4. 登录后进入「仪表盘」页面，完成以下配置：
- 填写接收通知的邮箱（选填，建议填写）
- 开启/关闭「自动签到」（默认开启）
- 自定义GPS定位（可选，留空则使用学校官方定位）
- 点击「保存设置」完成配置
 
3. 核心操作说明
 
（1）手动触发签到
 
- 在仪表盘页面，点击「手动签到」按钮
- 系统会在后台执行完整签到流程，结果会实时写入日志
- 若配置了邮箱，签到结果会发送到你的邮箱
 
（2）管理员操作（仅ADMIN_STU_ID）
 
- 登录后可查看所有已注册用户列表
- 可修改其他用户的邮箱、自动签到状态、定位信息
- 可替其他用户触发手动签到
 
（3）查看日志
 
- 点击仪表盘的「查看日志」按钮，可查看最近30条系统日志
- 日志包含签到流程、错误信息、邮件发送状态等，方便排查问题
 
（4）自动签到
 
- 系统默认每日21:30自动触发签到（可在 core_sign.py 的 Config 类中修改 SIGN_TIME_START / SIGN_TIME_END 调整时段）
- 自动签到结果会更新到「最后签到状态」，并发送邮件通知
 
五、常见问题与解决
 
1. 登录失败
 
- 检查学号/密码是否正确（密码为安工大晚寝签到系统密码，非校园网密码）
- 查看日志文件 logs.txt ，若提示「Token失效/账号或密码错误」，确认密码是否修改过
 
2. 邮件接收不到
 
- 确认 SMTP_USER 和 SMTP_PWD 填写正确（授权码而非登录密码）
- 检查QQ邮箱的SMTP服务是否开启
- 查看日志中「发送邮件失败」的具体错误信息（如网络问题、邮箱格式错误）
 
3. 内网穿透启动失败
 
- 确认 cloudflared.exe 在项目根目录，且路径配置正确
- Windows系统若提示「权限不足」，右键以管理员身份运行命令行
- Linux/macOS需替换 cloudflared 为对应系统版本，并修改 CLOUDFLARED_PATH 
 
4. 签到提示「已完成签到」
 
- 属于正常逻辑，系统检测到当日已签到会自动跳过，避免重复提交
- 若实际未签到却提示该信息，可手动触发签到或联系管理员排查
 
5. 依赖安装报错
 
- 升级pip： python -m pip install --upgrade pip 
- 若提示 aiohttp 安装失败，执行： pip install aiohttp==3.9.1 （指定兼容版本）
 
六、注意事项
 
1. 免责声明：本工具仅用于学习交流，请勿用于违规用途，使用风险自负
2. 定时任务：系统启动后需保持运行状态，关闭程序则自动签到失效（建议部署在服务器/挂机的电脑上）
3. 隐私保护：数据库 users.db 存储了你的学号/密码/邮箱，请勿分享给他人
4. 版本适配：若学校接口更新导致签到失败，可基于本项目的核心逻辑，通过Gemini/豆包修改接口参数
5. 日志清理： logs.txt 会自动按10MB分割，保留5个备份，无需手动清理

总结
 
1. 核心操作流程：配置环境→修改核心参数→启动程序→登录配置→使用自动/手动签到；
2. 关键配置项：管理员学号、QQ邮箱授权码、cloudflared路径，需优先确认填写正确；
3. 故障排查优先查看 logs.txt ，常见问题（登录/邮件/穿透）均可通过日志定位原因。
